Нийтийн хайлтын индекст орсон постын гарчиг, хэсгийг цуглуулна. Хаалттай групп хамрахгүй. Үр дүнгийн бүтэн текст, нийтэлсэн огноог эх пост дээр шалгаарай.

Хугацаатай багц · Хэрэглээ нь хайлтын нийлүүлэгчид илгээсэн API хүсэлтийн тоо. Төлбөр банкны шилжүүлгээр, админ баталгаажуулсны дараа идэвхжинэ. Автомат картын суутгал байхгүй. Шинэ багц батлагдах үед квот шинээр тооцогдоно; өмнөх үлдэгдэл шилжихгүй.
