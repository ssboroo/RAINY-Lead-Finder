Шинэ боломж цуглуулах

Нийтийн хайлтын индекст орсон постын гарчиг, хэсгийг цуглуулна. Хаалттай групп хамрахгүй. Үр дүнгийн бүтэн текст, нийтэлсэн огноог эх пост дээр шалгаарай.

1–6 цагийн нарийвчлалтай хайлт нь зөвхөн нийлүүлэгчийн цагийн мэдээлэлтэй үр дүнг ялгана. Энэ нь Facebook постын баталгаатай нийтэлсэн цаг биш. Гүн хайлт API хэрэглээ нэмэгдүүлнэ.

Групп / Page эх сурвалжууд

Сонгосон эх сурвалжийн зөвхөн индекст орсон постуудыг хайна. Эх сурвалж нэмээгүй бол Facebook даяарх нийтийн индексээс хайна.
