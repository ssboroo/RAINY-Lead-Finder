Нууцлал ба өгөгдөл

RAINY Lead Finder нь нэг байгууллагын хүсэлт, борлуулалтыг удирдах ажлын орчин юм. Facebook-ээр нэвтрэхэд таны app-scoped Facebook ID болон нэрийг зөвхөн нэвтрэлтийг баталгаажуулах, зөвшөөрөгдсөн хэрэглэгчийг танихад ашиглана.

Facebook access token-ийг баталгаажуулалтын явцад серверийн санах ойд түр ашиглаж, өгөгдлийн санд хадгалахгүй. Нэвтрэх session-д нэр, ID, нэвтрэх хэлбэрийг хадгалж, 8 цагийн хүчинтэй HttpOnly cookie ашиглана. Facebook нууц үгийг энэ сайт авахгүй.

Гарах үед тухайн session устна. Хугацаа дууссан session болон OAuth хүсэлтийг дараагийн нэвтрэлтийн ажиллагааны үеэр цэвэрлэнэ. Lead-ийн текст, холбоос, тэмдэглэл нь байгууллагын серверийн өгөгдлийн санд хадгалагдана. Хайлт хийхэд тохируулсан түлхүүр үгс Brave Search API-д дамжина. Хэрэглэгч мэдээллээ CSV эсвэл JSON-оор татаж болно.

Имэйл бүртгэл, subscription

Имэйлээр бүртгүүлэхэд нэр, имэйл, scrypt хэштэй нууц үг хадгална. Хэрэглэгч бүр тусдаа ажлын орчинтой. Багцын нэхэмжлэх, шилжүүлгийн лавлагаа, хугацаа, API хэрэглээний тоолуурыг subscription үйлчилгээ үзүүлэхэд ашиглана. Картын мэдээлэл авахгүй. API түлхүүрүүд серверийн тусдаа түлхүүрээр AES-GCM шифрлэгдэнэ.

Өгөгдөл устгах хүсэлт

Өөрийн хандалтыг цуцлахдаа эхлээд сайтаас гарч, Facebook-ийн Apps and Websites тохиргооноос энэ аппыг устгана. Серверт үлдсэн session болон байгууллагын lead бүртгэлийг бүрэн устгуулах бол таныг энэ ажлын орчинд урьсан байгууллагын админд хандана уу. Админ нь Facebook ID-аар холбогдох session-уудыг устгаж, lead бүртгэлийг нөөц болон үндсэн сангаас устгах ёстой.

Энэ хувилбарт хэрэглэгчийн өөрөө бүрэн устгах урсгал, олон байгууллагын бүртгэл байхгүй. Нийтэд үйлчилгээ нээхээс өмнө оператор нь өөрийн холбоо барих мэдээлэл, хадгалах хугацаа, устгах хүсэлтийг хүлээн авах сувгийг энд нэмэх шаардлагатай.
